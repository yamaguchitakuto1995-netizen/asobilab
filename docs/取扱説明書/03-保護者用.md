## 2. 振替申請（ログイン不要）

### 2-1. アクセス方法

ブラウザ（スマートフォン・パソコン）で、教室からお知らせされた URL を開いてください。

```
https://（教室から案内されたドメイン）/apply
```

- ログインは **不要** です
- LINE や QR コードのリンクからも開けます

### 2-2. 申請の流れ（6ステップ）

<table>
  <thead>
    <tr>
      <th style="width:12%">ステップ</th>
      <th>操作内容</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>1</strong></td>
      <td>お名前・所属教室・学年を入力して本人確認</td>
    </tr>
    <tr>
      <td><strong>2</strong></td>
      <td>（該当者のみ）兄弟姉妹と一緒に申請する場合は参加者を選択</td>
    </tr>
    <tr>
      <td><strong>3</strong></td>
      <td>欠席にしたい授業（振替の元）をカードから選択</td>
    </tr>
    <tr>
      <td><strong>4</strong></td>
      <td>振替先の日付を選択（今日から約4ヶ月先まで）</td>
    </tr>
    <tr>
      <td><strong>5</strong></td>
      <td>空いているコマを選択（満員は灰色表示）</td>
    </tr>
    <tr>
      <td><strong>6</strong></td>
      <td>内容を確認して申請を完了</td>
    </tr>
  </tbody>
</table>

#### ステップ 1：本人確認

<table>
  <thead>
    <tr>
      <th style="width:22%">項目</th>
      <th>入力のポイント</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>お名前</td>
      <td>教室登録と<strong>完全一致</strong>（スペースの有無も含む）</td>
    </tr>
    <tr>
      <td>所属教室</td>
      <td>プルダウンから選択</td>
    </tr>
    <tr>
      <td>学年</td>
      <td>プルダウンから選択</td>
    </tr>
  </tbody>
</table>

<blockquote class="callout-warn">
<p><strong>うまく進めない場合</strong></p>
<ul>
<li>名前・教室・学年のいずれかが登録と異なる</li>
<li>同姓同名・同教室・同学年のお子様が複数いる（教室へ連絡）</li>
</ul>
</blockquote>

#### ステップ 3：欠席する授業の選択

「出席予定」または「振替予定」のカードから、欠席にしたい授業を 1 つ選びます。

<table>
  <thead>
    <tr>
      <th>カードの表示</th>
      <th>意味</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>日付</td>
      <td>欠席にする授業日（振替授業の場合は「振替日」と表示）</td>
    </tr>
    <tr>
      <td>実施教室</td>
      <td>その授業が行われる教室（所属教室と異なる場合あり）</td>
    </tr>
    <tr>
      <td>コマ・教科</td>
      <td>何コマ目・どの教科か</td>
    </tr>
    <tr>
      <td>出席予定 / 振替予定</td>
      <td>現在の予定状態</td>
    </tr>
  </tbody>
</table>

<blockquote class="callout-tip">
<p><strong>ポイント</strong></p>
<ul>
<li>所属教室のレギュラー授業を欠席し、<strong>別教室の空きコマ</strong>へ振替できます</li>
<li>すでに振替した授業（振替予定）を、<strong>別のコマへ再度振り替え</strong>することもできます</li>
</ul>
</blockquote>

## 3. 予定の確認（ログイン必要）

### 3-1. 初回セットアップ

<table>
  <thead>
    <tr>
      <th style="width:8%">順</th>
      <th>手順</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>保護者ご本人が <code>/login</code> から新規登録</td>
    </tr>
    <tr>
      <td>2</td>
      <td>教室スタッフが生徒編集画面で保護者メールを紐付け</td>
    </tr>
    <tr>
      <td>3</td>
      <td>保護者がログイン →「お子様の予定」画面が開く</td>
    </tr>
  </tbody>
</table>

### 3-2. 確認できる内容

- 氏名・学年・所属教室
- 兄弟姉妹の情報（登録されている場合）
- **次回テキスト**（ロボット / プログラミング）
- **今後の予定**（今日から約 120 日先まで）
- 振替の場合、元の欠席コマの情報

## 4. よくある質問

<table>
  <thead>
    <tr>
      <th style="width:38%">質問</th>
      <th>回答</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>振替申請にログインは必要？</td>

    <tr>

    </tr>

    </tr>

      <td>パスワードを忘れた</td>

    </tr>
  </tbody>
