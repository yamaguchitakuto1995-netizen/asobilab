## 2. ホーム — 本日のコマ表

### 2-1. コマ表で確認すること

<table>
  <thead>
    <tr><th>確認項目</th><th>説明</th></tr>
  </thead>
  <tbody>
    <tr><td>出席予定の生徒</td><td>白いカードで表示</td></tr>
    <tr><td>欠席・欠席予定</td><td><strong>灰色カード</strong>＋上部バナー</td></tr>
    <tr><td>振替予定</td><td>実施教室に注意</td></tr>
    <tr><td>本日のテキスト</td><td>上部の教材サマリー（欠席予定は除外）</td></tr>
    <tr><td>前回の備考</td><td>各生徒カード内</td></tr>
  </tbody>
</table>

### 2-2. 操作の基本

<table>
  <thead>
    <tr><th>操作</th><th>方法</th></tr>
  </thead>
  <tbody>
    <tr><td>日付変更</td><td>前日 / 翌日ボタン、または日付ピッカー</td></tr>
    <tr><td>絞り込み</td><td>教室・教科フィルター（複数選択可）</td></tr>
    <tr><td>コマ切替</td><td>横スワイプ（スマホ）または横スクロール（PC）</td></tr>
  </tbody>
</table>

### 2-3. 生徒カードの見分け方

<table>
  <thead>
    <tr><th style="width:32%">表示</th><th>意味</th></tr>
  </thead>
  <tbody>
    <tr><td>白いカード</td><td>出席予定・振替予定など通常</td></tr>
    <tr><td>灰色カード ＋「欠席予定」「欠席」バナー</td><td>欠席・欠席予定</td></tr>
    <tr><td>出欠「欠席」（赤太字）</td><td>欠席であることを強調</td></tr>
  </tbody>
</table>

### 2-4. 出席確認（最重要）

「出席確認」ボタン → 全画面ダイアログで入力：

<table>
  <thead>
    <tr><th style="width:22%">項目</th><th>内容</th></tr>
  </thead>
  <tbody>
    <tr><td>出欠</td><td>出席 / 遅刻 / 欠席 / 振替</td></tr>
    <tr><td>本日のテキスト</td><td>カリキュラムから選択</td></tr>
    <tr><td>備考</td><td>次回担当者向けメモ（次回コマ表に表示）</td></tr>
  </tbody>
</table>

<blockquote class="callout-warn">
<p><strong>次回テキストの自動更新ルール</strong></p>
<ul>
<li><strong>出席・遅刻・振替</strong>で記録 → 次回テキストが 1 つ進む</li>
<li><strong>欠席</strong>で記録 → 次回テキストは進まない</li>
</ul>
</blockquote>

## 4. 振替申請への対応

### 4-1. 保護者の申請後（自動反映）

<table>
  <thead>
    <tr><th>対象</th><th>変化</th></tr>
  </thead>
  <tbody>
    <tr><td>欠席にした元の授業</td><td>欠席予定（灰色カード）</td></tr>
    <tr><td>振替先</td><td>振替予定として登録</td></tr>
    <tr><td>教室の承認</td><td><strong>不要</strong></td></tr>
  </tbody>
</table>

### 4-2. 振替当日

1. コマ表で振替予定の生徒・**実施教室**を確認
2. 授業後「出席確認」→ 出欠 **「振替」** を選択

### 4-3. 取消・変更

保護者画面からは取消不可。生徒詳細の「今後の予定」から振替行を削除し、必要なら元の授業を出席予定に戻す。

## 5. 日常業務チェックリスト

### 授業当日

- [ ] 本日の日付でコマ表を開く
- [ ] 灰色カード（欠席予定）を確認
- [ ] 振替予定の実施教室を確認
- [ ] 教材サマリーでテキストを準備
- [ ] 各生徒の出席確認で記録

### 保護者対応

- [ ] 振替 URL（`/apply`）を案内
- [ ] 予定確認希望 → 保護者登録 → 生徒編集で紐付け
